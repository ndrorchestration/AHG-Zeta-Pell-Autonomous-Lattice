# AHG Zeta-Pell Autonomous Lattice

## Overview

Experimental control-plane simulation combining PID control, Savitzky-Golay filtering, Kalman estimation/reset behavior, and a silver-ratio/Pell-derived timing anchor.

> **Epistemic status:** Experimental. This repository is not currently production-certified. Historical benchmark values are retained as historical claims and must not be treated as independently validated unless their source telemetry and derivation are reproduced.

## Evidence Status

The repository contains historical benchmark assertions including PAR 88.1%, a 2-cycle recovery claim, peak entropy 0.8616, and a 200x jitter-resilience claim. The Pass-1 audit found that these values are not all independently reproducible from the sampled source cells. In particular:

- the jitter multiplier lacks a defined `1x` baseline;
- the final 2-cycle recovery claim requires a closed trace from the intermediate 4-cycle retest;
- hardcoded benchmark dictionaries establish recorded values, not their independent derivation;
- the notebook's "Hecke Operator" terminology does not correspond to an implemented Hecke operator and should be treated as misleading project terminology;
- the silver-ratio/Pell identity is standard mathematics, but it does not by itself prove stability, spectral optimality, or entropy-reduction claims.

See [`docs/AUDIT_PASS_1.md`](docs/AUDIT_PASS_1.md) for the Fact-Fiction Ledger and sampling scope.

## Core Experimental Components

1. **PID-based control:** continuous modulation and flicker-mitigation experiments.
2. **Savitzky-Golay filtering:** signal smoothing; latency and zero-lag claims require measurement-specific qualification.
3. **Kalman estimation/reset:** covariance-state estimation and recovery experiments.
4. **Silver Ratio / Pell anchor:** deterministic timing reference based on the standard identity `1 + sqrt(2)` as the limiting ratio associated with Pell-number sequences.
